# SORI

Windows 시스템 오디오를 실시간 자막으로 보여 주고, 녹음·동영상 파일을 전사하는 로컬 전사 앱입니다.

이 저장소는 **설치 파일 배포 전용**입니다. 소스 코드는 여기에 없습니다.

## 내려받기

[Releases](https://github.com/Gomtanga/SORI/releases)에서 `SORI-Setup-<버전>-x64.exe`를 받아 실행합니다.

- Windows 10 1903 이상 또는 Windows 11, x64
- Python이 들어 있어 따로 설치할 필요가 없습니다.
- 음성 모델과 검색 모델은 들어 있지 않습니다. 처음 쓸 때 크기와 출처를 보여 주고 확인을 받은 뒤 내려받습니다.
- 기록과 모델은 `%LOCALAPPDATA%\SORI`에 저장되며, 앱을 지우거나 업데이트해도 남습니다.

## 파일 확인

릴리스마다 `release-manifest.json`이 함께 올라갑니다. 버전, 크기, SHA-256, 서명자 지문이 들어 있습니다. 내려받은 파일은 이렇게 확인합니다.

```powershell
Get-FileHash .\SORI-Setup-0.5.0-x64.exe -Algorithm SHA256
```

## 서명

지금 설치 파일은 **자체 서명 인증서**로 서명돼 있습니다.

- 지문: `F4E057B9644DBFB499AD2B3E8508F104EEB5022C`
- 공인 인증서가 아니어서 Windows가 "알 수 없는 게시자" 경고를 보여 줄 수 있습니다.
- 앱 안의 자동 업데이트는 Windows가 서명을 유효(Valid)로 판정하고 지문이 허용 목록에 있는 파일만 설치합니다.

## 개인정보

음성과 기록은 이 PC 안에서만 처리합니다. 인터넷은 모델을 내려받을 때와 업데이트를 확인할 때만 씁니다.
